Comment ça marche

  1. Jour montre une journée en grand, Semaine la semaine entière, Devoirs ce qu'il reste à faire. Le bandeau du haut annonce le cours en cours ou le prochain, avec la salle.
  2. La pastille Semaine A ou Semaine B en haut indique la quinzaine. Le bouton Auto n'affiche que les cours de cette semaine-là ; Les deux montre tout.
  3. Pour noter un devoir, touche simplement le cours concerné : la matière et la date sont déjà remplies. Le bouton + Ajouter un devoir fait la même chose depuis la vue Devoirs.
  4. Pour corriger l'emploi du temps — une salle, un prof, un cours déplacé — appuie sur Modifier, touche le cours, change ce qu'il faut, puis Terminer.
  5. Un code est demandé une fois par session avant d'enregistrer. Tout ce qui est enregistré se retrouve automatiquement sur les autres appareils.
